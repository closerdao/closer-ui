# Docs index

One line per doc. **Reference** docs describe how things work now and are kept current. **Historical** docs record a plan, ticket or idea at a point in time; don't treat them as the current design.

Root files: `CONTEXT.md` (glossary and settled decisions), `README.md` (setup), `STRATEGY.md`, `MIGRATE_PLATFORM_STRIPE_ACCOUNT.md` (runbook), `AGENTS.md`.

## Reference

- `residencies-api.md`: how closer-ui talks to the API for volunteer residencies.
- `quests-ui-backend-notes.md`: what the Quests UI expects from the backend.
- `village-app-provisioning-contract.md`: contract between the Village app and provisioning.
- `static-pages/`: TDF marketing pages as Page-model JSON, seed and migration artifacts. Start with its `README.md`.
- `agents/`: issue tracker, triage labels and domain-doc conventions for agent skills.
- `../packages/closer/docs/booking-food-fields-for-backend.md`: how the frontend uses booking food fields.
- `../packages/closer/docs/credits-purchase-api.md`: API contract for buying credits.
- `../packages/closer/docs/profile-places-backend.md`: profile homes and upcoming visits.
